SHOLuminance-AIP 0.6.1

Crée une luminance monochrome à partir de SII, Ha et OIII avec Moyenne, Lighten ou Screen. Pieds séparés dans les réglages avancés et histogrammes superposés en couleurs, avec luminance finale facultative.

Menu : Script > CCD1024 > SHOLuminance-AIP, avec l'icône AIP.

Paquet PixInsight 0.6.1 · Code, icône et notice

Installer dans PixInsight

Dans Resources > Updates > Manage Repositories, ajouter :

https://ccd1024.github.io/AIP-Scripts/

Puis rechercher les mises à jour et redémarrer PixInsight si demandé.

Le serveur fournit updates.xri et l'archive de la version 1.01.

Cette version du script et du dépôt est non signée. Une signature certifiée PixInsight pourra être ajoutée à une prochaine publication.

Après installation : Script > CCD1024 > SHORGB-AIP, avec l’icône AIP.

Utilisation rapide

  1. Sélectionner les sources utiles et choisir un preset.
  2. Préparer / Rafraîchir le preview.
  3. Ajuster les coefficients, le pied et les offsets.
  4. Créer et enregistrer l'image finale.

Le STF ne modifie que l'affichage. Unlinked STF ne représente pas la balance des couleurs de l'image finale.

PixInsight 1.9.4 à 1.9.6 avec V8. Vérifications effectuées sur 1.9.6 pour macOS.
